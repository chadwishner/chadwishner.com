# chadwishner.com

A personal website disguised as a macOS Terminal window. Visitors interact by typing commands to learn about me, view my projects, or open my social links.

Built with React + Vite.

## Commands

| Command | Description |
|---------|-------------|
| `help` | List all available commands |
| `about` | Learn about me |
| `skills` | View my technical skills |
| `experience` | View my work experience |
| `projects` | See my projects |
| `education` | View my education |
| `contact` | Get my contact info |
| `github` | Open my GitHub profile |
| `linkedin` | Open my LinkedIn profile |
| `resume` | Open my resume |
| `email` | Send me an email |
| `neofetch` | Display system info (with visitor IP & browser) |
| `whoami` | Show visitor info |
| `ls`, `cat`, `pwd`, `date` | Unix-style commands |
| `clear` | Clear the terminal |
